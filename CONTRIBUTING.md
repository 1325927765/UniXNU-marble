# Contributing

Use GitHub Issues for technical discussion and focused proposals. Include the device variant, relevant source revision, the command or action tested, the observed result and the expected result. Mark untested ideas explicitly.

Current areas of interest:

- Qualcomm GENI SPI integration and Goodix touch handling for marble.
- The XNU input path and IOHID event delivery.
- Stable display presentation and console handoff.
- Source provenance, reproducible builds and migration to the official UniXNU device format.

Before submitting code, identify its origin and license, retain copyright notices, and distinguish host checks from physical-device tests. Do not claim iOS touch support based only on recovery touch tests.

Do not upload credentials, personal device identifiers, private captures, IPSWs, Apple system images, or proprietary firmware. Prefer public source links and non-sensitive, minimal diagnostic excerpts. Do not offer flashing instructions until the required source and test procedure are available for review.

The device-repository requirements are documented by upstream:

- [Device repository](https://unixnu.com/porting/device-repository)
- [Porting records](https://unixnu.com/porting/records)
- [Migration guide](https://unixnu.com/porting/migration)

This repository is community-maintained and does not imply endorsement or official support from UniXNU, Apple, Xiaomi or Qualcomm.
